## 📌 Опис проєкту

**Study Planner** — це навчальний клієнтський застосунок для планування академічних завдань, розроблений на базі бібліотеки React 19 та TypeScript. Застосунок демонструє ключові фундаментальні концепції React:
* Декомпозиція інтерфейсу на незалежні компоненти відповідно до принципу єдиної відповідальності (SRP).
* Передача даних та зворотний зв'язок через **props** та **callback-функції**.
* Керування реактивним локальним станом за допомогою хука **`useState`**.
* Суворе дотримання принципу **незмінності (Immutability)** при модифікації масивів та об'єктів.
* Обчислювані значення (Derived State) для лічильників та статистики без дублювання стану.
* Рендеринг списків через `.map()` зі стабільними унікальними ключами `key`.
* Різні сценарії **умовного рендерингу (Conditional Rendering)**.
* Стилізація за методологією **SCSS + BEM** (Block__Element--Modifier).

## ⚙️ Функціональні можливості

1. **Перегляд завдань:** Відображення списку з назвою, детальним описом, категорією та пріоритетом.
2. **Додавання завдання:** Форма з валідацією обов'язкової назви (порожні завдання блокуються без використання `alert`). Після додавання форма очищається.
3. **Зміна стану виконання:** Чекбокс перемикає завдання між станами «виконано» / «не виконано». Виконані завдання мають візуальне перекреслення, змінений колір та зменшену прозорість.
4. **Видалення завдання:** Кнопка видалення для кожного завдання.
5. **Фільтрація:** Перемикання режимів «Всі», «Виконані», «Не виконані» з візуальним підсвічуванням активної кнопки.
6. **Автоматична статистика:** Лічильники «Всього», «Виконано» (з відсотком) та «До виконання» рахуються динамічно на основі масиву без зайвих `useState`.
7. **Умовний рендеринг:**
   * Якщо список взагалі порожній: виводиться запрошення додати перше завдання.
   * Якщо за поточним фільтром немає результатів: виводиться відповідне повідомлення із пропозицією змінити фільтр.
8. **Додаткові можливості:**
   * **Сортування за пріоритетом:** можливість сортувати список за спаданням або зростанням важливості (High $\rightarrow$ Low або Low $\rightarrow$ High).
   * **Кольорові бейджі пріоритетів:** візуальне кодування червоним (High), жовтим (Medium) та блакитним (Low).
   * **Лічильники в кнопках фільтрів:** відображення кількості біля кожної категорії фільтрації.
   * **Очищення виконаних:** кнопка для масового видалення завершених завдань в один клік.

## 🚀 Запуск проєкту локально

```bash
# Перехід у робочу папку
cd study-planner

# Встановлення залежностей (якщо не встановлено)
npm install

# Запуск локального сервера розробки
npm run dev

# Перевірка лінтером ESLint
npm run lint

# Збірка продакшн-білда з перевіркою типів TypeScript
npm run build
```
